# Sales Performance Dashboard (Power BI)

## Project Overview
This project is an interactive Sales Performance Dashboard built in Power BI using the Superstore dataset. The dashboard provides insights into sales, profit, customer segments, product performance, and regional trends to support data-driven business decisions.

## Project Goal
The goal of this project is to analyze sales performance across different regions, categories, and customer segments while identifying profitable and loss-making areas of the business.

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value

---

## Features
- Interactive slicers for Year, Region, Category, and Segment
- Sales and profit trend analysis
- Product performance tracking
- Regional sales comparison
- Profitability analysis by sub-category
- Dynamic and user-friendly dashboard layout

---

## Key Insights
- Generated over $2.3M in total sales
- Achieved $286K total profit
- Technology was the highest-performing category
- Consumer segment contributed the largest share of sales
- Some sub-categories showed negative profitability
